# Entrega do Projeto

Esta pasta reúne os materiais finais pedidos para avaliação. Não guardar aqui
segredos, passwords, tokens ou exports com dados reais de utilizadores.

## Estrutura

| Pasta | Conteúdo esperado |
| --- | --- |
| `poster/` | Poster final do projeto |
| `video/` | Vídeo de apresentação ou demonstração |
| `feedback/` | Feedback recebido durante o desenvolvimento |
| `autoavaliacao/` | Documento de autoavaliação |
| `relatorio/` | Relatório final |
| `deploy-railway/` | Guia para colocar a aplicação a funcionar no Railway |

## Convenções

- Usar nomes descritivos e estáveis, por exemplo `poster-vision4farms.pdf`.
- Preferir PDF para documentos finais.
- Não substituir ficheiros finais sem rever o histórico do Git.
- Confirmar o tamanho do vídeo antes de o adicionar. Para vídeos grandes,
  usar Git LFS ou colocar nesta pasta um ficheiro `link-video.md` com o URL.
